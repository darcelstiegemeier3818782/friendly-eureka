About This Project

This is a no-build static site that still ships a few delightful features:

  1. PWA with offline caching (see sw.js)
  2. Client-side search (see data.js & search.js)
  3. WCAG color contrast checker with auto-fix (see contrast.js)
  4. Generative SVG art with a saver (see gallery.js)

All files live at the root (no folders) so you can drop them into a GitHub Pages repo as-is.

© Techy Static PWA · Built with semantic HTML, accessible CSS, and vanilla JS.
